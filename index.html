Manager · Navigator · Resource pack

계정을 정리하고,
항로를 이어 갑니다.

여러 게임 계정을 한곳에서 관리하고 로그인 없이 독립 네비게이터를 실행합니다. 항적과 경로, 게임 창 전용 HUD, 커뮤니티 리소스팩까지 같은 작업 흐름에 담았습니다.

DHO Manager 2.1.x · Windows · 비공식 팬 프로젝트
01 / MANAGER

계정 실행 관리

계정 카드, 토큰 상태, 창 배치와 재접속 흐름을 한 화면에서 관리합니다.

02 / NAVIGATOR

독립 항해 지원

측량 좌표, 항적, 목적지 경로와 조향 정보를 로그인 없이 확인합니다.

03 / PACK

개방형 화면 구성

지도 데이터, 거점, 마커와 HUD 외형을 `.dho-pack`으로 조합합니다.

One workspace

두 클라이언트 옆에서도 필요한 정보만 남깁니다.

Navigator

네비게이터는 Manager 로그인에 종속되지 않습니다. 자동 감지 또는 지정 PID를 따라가며 HUD는 선택한 대항해시대 클라이언트 위에만 표시됩니다.

ROUTE

항로와 조향

현재 진행 방향, 목적지 수렴 정보, 자동 보조 경로와 편집 가능한 경유지를 제공합니다.

TRACK

오래 남는 항적

항차 단위로 보존하고 현재 항차, 이전 항차 또는 전체 기록을 골라 표시합니다.

HUD

게임 창 전용 HUD

지도, 항해 정보와 조향 표시를 게임 위에 붙이고 각 위치와 크기를 조정합니다.

LOCAL FIRST

읽기 전용 캡처

화면에 보이는 픽셀을 판독하며 게임 메모리, 패킷, DLL 주입과 입력 자동화를 사용하지 않습니다.

Resource pack ecosystem

화면의 개성은 팩으로, 배치는 사용자 설정으로.

커뮤니티 리소스팩

지도·거점·마커·HUD 스킨을 한 팩에 넣거나 필요한 구성요소만 배포할 수 있습니다. 설치 전 앱이 파일 해시와 안전 제한을 검사합니다.

팩 만들기커뮤니티 팩

규격 1 문서

매니페스트, 구성요소 스키마, 정적 자산 제한, 해시 생성과 검증 명령을 API 참조 형식으로 정리했습니다.

문서 시작

Navigator only

Manager 없이 네비게이터로 바로 시작합니다.

01
실행 파일 바로가기 만들기

DHO-Manager.exe를 우클릭해 바로 가기를 만듭니다.

02
바로가기 속성 열기

새 바로가기를 우클릭하고 속성 → 바로 가기 탭을 엽니다.

03
대상 끝에 인자 추가

실행 파일 경로 뒤에 공백 하나와 --navigator를 붙입니다.

04
바로가기로 실행

Manager 로그인 화면 없이 자동 감지 네비게이터가 열립니다.

바로가기 대상 예시"C:\Program Files\DHO Manager\DHO-Manager.exe" --navigator

하이픈은 반드시 2개입니다. 실행 파일 경로에 공백이 있으면 경로 전체를 큰따옴표로 감싸고, 닫는 따옴표 뒤에 공백을 둔 다음 --navigator를 입력하세요.

Safety boundary

로컬 데이터와 게임 프로세스 사이의 경계를 지킵니다.

선언형 팩HTML, JavaScript, DLL과 임의 CSS를 실행하지 않습니다.
로컬 우선항적, 설정과 계정 데이터는 사용자 PC에 저장됩니다.
명시적 배포지도와 거점 데이터는 릴리즈 시 검증된 스냅샷으로 포함됩니다.
