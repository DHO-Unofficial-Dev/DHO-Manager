JSON Schema

사람이 API 문서를 읽으며 편집할 때 IDE 자동완성과 오류 표시를 제공하고, AI 에이전트가 허용된 필드와 범위를 추측하지 않도록 돕는 규격 1 보조 자료입니다.

최종 판정 순서

실행 중인 Manager 검증기 → 공개 Node 검증기 → JSON Schema → 설명 문서 순서로 우선합니다. Schema는 편집 보조이며 최종 아카이브 검증을 대신하지 않습니다.

스키마 목록

ROOTmanifest.schema.json

팩 식별, 호환성, 해시와 모든 구성요소 토큰.

POIpoi-data.schema.json

거점 추가·대체·숨김과 연결 입구.

MAPcoastline.schema.json

16384×8192 좌표계의 해안선 폴리곤.

MAPsea-regions.schema.json

해역 면, 라벨 위치와 경계 정의.

편집기에 연결

manifest.json 루트에 다음 주석용 필드를 넣는 방식은 현재 허용되지 않습니다. 대신 VS Code 설정이나 사용하는 JSON 편집기의 파일 매핑 기능으로 URL을 연결하세요.

https://manager.dhoport.app/resource-pack/schema/manifest.schema.json

팩에 스키마 URL 자체를 포함하지 않아도 됩니다. 최종 공유 파일에는 규격에서 허용한 키만 남겨야 합니다.

지도 데이터 주의

mapData는 단순한 표시점 모음이 아닙니다. 해안선과 해역 경계는 이웃 면의 접합, 세계 좌표 경계, 홀 소속과 동일한 원본 버전을 함께 검증해야 합니다. 기존 지도를 보고 임의의 사각형이나 보정점을 만들지 말고 정식 제공자의 canonical 데이터와 검수 절차를 사용하세요.
