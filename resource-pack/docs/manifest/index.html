문서/manifest.json

manifest.json

팩의 식별자, 출처, 호환 범위, 파일 무결성과 구성요소 진입점을 선언하는 루트 문서입니다. UTF-8 JSON으로 저장하고 팩 최상위에 정확히 한 개만 둡니다.

편집기 지원

manifest JSON Schema를 IDE에 연결하면 필드 자동완성과 값 범위 검사를 받을 수 있습니다. 최종 파일은 Node 검증기로 다시 확인하세요.

전체 예시

{
  "formatVersion": 1,
  "packId": "community.example.navigation",
  "name": "예시 항해팩",
  "author": "제작자 이름",
  "version": "0.1.0",
  "license": "CC-BY-4.0",
  "publisher": {
    "id": "community.example",
    "name": "예시 배포자",
    "url": "https://example.com"
  },
  "source": {
    "name": "제작자 사이트",
    "url": "https://example.com/dho-pack"
  },
  "thumbnail": "thumbnail.webp",
  "compatibility": {
    "minimumManagerVersion": "2.1.0",
    "maximumManagerVersionExclusive": "3.0.0"
  },
  "files": {},
  "componentRequirements": {
    "markerSet": ["mapData"]
  },
  "components": {
    "poiData": {
      "id": "community.example.navigation.poi-data",
      "name": "예시 추가 거점",
      "dataVersion": "2026-08-06",
      "coordinateSpace": "game 16384x8192",
      "source": "components/poi-data/pois.json"
    }
  }
}

루트 필드

필드형식필수설명
formatVersion정수예새 팩은 1만 사용합니다.
packId문자열예팩의 안정 ID. publisher.id와 같거나 그 ID로 시작해야 합니다.
name문자열예사용자 화면에 표시할 팩 이름입니다.
author문자열예개인 또는 팀의 표시명입니다.
versionSemVer예팩 자체 버전입니다. 앱 버전과 독립적입니다.
license문자열예자산과 데이터의 이용 조건입니다.
publisher객체예배포자 귀속 정보입니다.
source객체예데이터·자산의 출처입니다.
thumbnail경로아니요팩 카드용 이미지입니다.
compatibility객체예호환 가능한 Manager 버전 범위입니다.
files객체예모든 비매니페스트 파일 경로와 SHA-256입니다.
componentRequirements객체아니요같은 팩 구성요소 사이의 의존성입니다.
components객체예팩이 제공하는 구성요소 선언입니다.

식별자 규칙

packId, publisher.id와 구성요소 ID는 소문자 영문 또는 숫자로 시작하고 이후 소문자 영문, 숫자, 마침표, 밑줄, 하이픈만 사용합니다. 최대 128자입니다.

community.example
community.example.navigation
community.example.navigation.marker-set
업데이트 안정성

같은 팩을 업데이트할 때 packId를 바꾸지 말고 version만 올립니다. ID를 바꾸면 앱은 별도의 팩으로 취급합니다.

publisher와 source

publisher.id, publisher.name, source.name은 필수입니다. 선택 URL은 HTTPS만 허용합니다. 배포자 정보는 출처 귀속이며 디지털 서명이나 서비스 제공자 인증이 아닙니다.

필드제한의미
publisher.id안정 ID팩 ID의 네임스페이스를 소유하는 표시용 식별자
publisher.name문자열설치 화면에 표시되는 배포자
publisher.urlHTTPS배포자 소개 주소
source.name문자열원본 데이터 또는 자산 출처 설명
source.urlHTTPS원본 또는 제작 문서 주소

호환 범위

minimumManagerVersion은 포함 하한, maximumManagerVersionExclusive는 제외 상한입니다. 둘 다 SemVer를 사용합니다.

"compatibility": {
  "minimumManagerVersion": "2.1.0",
  "maximumManagerVersionExclusive": "3.0.0"
}

이 예시는 2.1.0 이상, 3.0.0 미만을 뜻합니다. 새 선택 필드를 추가한 2.1.x 앱은 필드가 없는 기존 1.1.x 팩에 내장 기본값을 적용합니다.

files 무결성

키는 팩 루트 기준 POSIX 경로, 값은 sha256: 접두사가 붙은 소문자 64자리 SHA-256입니다. manifest.json 자체는 목록에서 제외하고 나머지 파일은 빠짐없이 포함합니다.

"files": {
  "thumbnail.webp": "sha256:c6d7…64자리…84af",
  "components/poi-data/pois.json": "sha256:88a1…64자리…12e0"
}

패키징 도구가 임시 매니페스트에 이 객체를 자동 생성하므로 일반적으로 손으로 작성하지 않습니다.

componentRequirements

한 구성요소가 같은 팩의 다른 구성요소와 함께 적용되어야 할 때만 선언합니다. 다른 팩이나 내장값으로 의존성을 충족할 수 없습니다.

  • 자기 자신, 중복과 순환 의존성은 거부됩니다.
  • 팩에 선언하지 않은 구성요소를 참조할 수 없습니다.
  • 설치·활성 전환 시 필수 구성요소가 원자적으로 함께 처리됩니다.
