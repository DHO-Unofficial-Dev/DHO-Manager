리소스팩 규격

`.dho-pack`은 DHO Navigator의 지도 데이터, 거점, 마커와 HUD 외형을 배포하는 선언형 패키지입니다. 이 문서는 새 팩 제작자가 사용하는 formatVersion 1을 설명합니다.

현재 기준

DHO Manager 2.1.x는 규격 1 팩을 검증하고 구성요소별로 설치합니다. 개발 중 사용한 규격 0은 읽기 호환만 유지하며 새 팩 제작에는 사용하지 않습니다.

동작 모델

리소스팩은 루트의 manifest.json과 정적 JSON·이미지 파일을 담은 ZIP 컨테이너입니다. 공유할 때 확장자는 반드시 .dho-pack을 사용합니다.

my-pack/
├─ manifest.json
├─ thumbnail.webp
└─ components/
   ├─ poi-data/pois.json
   └─ markers/ship.svg

앱은 파일을 연 시점에 구조, 크기, 경로, SHA-256과 구성요소 스키마를 검사합니다. 검사를 통과해도 즉시 적용하지 않으며, 설치 대화상자에서 사용자가 고른 구성요소만 로컬 스택에 저장합니다.

보안 경계

  • HTML, JavaScript, DLL, 임의 CSS와 실행 파일은 허용하지 않습니다.
  • 외부 URL은 출처 메타데이터일 뿐 런타임 요청이나 신뢰 인증을 의미하지 않습니다.
  • 마커는 PNG·WebP·제한된 정적 SVG를, 팩 썸네일은 PNG·WebP·JPEG·GIF를 읽습니다.
  • 리소스팩은 색상·선형·마커 외형을 정하고, 사용자의 위치·크기·투명도 설정은 덮어쓰지 않습니다.

빠른 시작

추가 거점이나 기본 화면 테마는 브라우저 생성기로 만들 수 있습니다. 이미지 마커, 해안선 데이터 또는 전체 토큰을 다루려면 Node.js 20 이상의 제작 도구를 사용합니다.

node tools/validate-pack.mjs ./my-pack
node tools/build-dho-pack.mjs ./my-pack ./dist/my-pack.dho-pack
node tools/verify-archive.mjs ./dist/my-pack.dho-pack
직접 ZIP 금지

files에는 manifest.json을 제외한 모든 파일의 SHA-256이 필요합니다. 공유본은 패키징 도구로 만들어야 앱 검증을 통과합니다.
