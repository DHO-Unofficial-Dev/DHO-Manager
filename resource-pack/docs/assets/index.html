파일과 정적 자산

팩은 재현 가능한 상대 경로와 제한된 정적 파일만 포함합니다. 확장자뿐 아니라 실제 파일 헤더, 크기와 내부 참조도 검사합니다.

아카이브 구조

컨테이너는 표준 ZIP이지만 사용자에게는 .dho-pack 확장자로 배포합니다. manifest.json은 루트에 있어야 하며 중첩된 최상위 폴더를 두지 않습니다.

example.dho-pack
├─ manifest.json
├─ thumbnail.webp
└─ components/
   ├─ map-data/
   │  ├─ coastline.json
   │  └─ sea-regions.json
   ├─ poi-data/pois.json
   └─ markers/
      ├─ ship.svg
      └─ destination.png

경로 규칙

  • 슬래시(/)를 사용하는 팩 루트 기준 상대 경로만 허용합니다.
  • 절대 경로, 역슬래시, 빈 구간, ., .. 구간은 거부합니다.
  • 선언한 경로와 파일명의 대소문자가 정확히 같아야 합니다.
  • .DS_Store와 __MACOSX는 패키징 단계에서 제외합니다.
  • files에 없는 파일과 실제로 존재하지 않는 선언 파일은 모두 오류입니다.

팩 썸네일

선택 필드 thumbnail은 팩 루트의 thumbnail.webp, thumbnail.png, thumbnail.jpg, thumbnail.jpeg, thumbnail.gif 중 하나를 가리킵니다.

  • 파일명은 용도를 명확히 하는 thumbnail.*만 허용합니다.
  • 카드 비율에 맞춘 16:9, 320×180 WebP를 권장합니다.
  • SVG는 팩 썸네일로 허용하지 않습니다.
  • 썸네일이 없는 기존 팩은 앱이 안전한 대체 이미지를 생성합니다.

래스터 이미지

마커 자산은 PNG와 WebP를 지원합니다. JPEG·GIF는 팩 썸네일에 사용할 수 있지만 투명 배경이 필요한 마커에는 적합하지 않습니다. 확장자와 파일 시그니처가 일치해야 합니다.

형식마커썸네일권장 용도
PNG지원지원선명한 픽셀·투명 마커
WebP지원지원작은 용량의 마커·미리보기
JPEG미지원지원사진형 썸네일
GIF미지원지원호환 썸네일

정적 SVG

SVG 마커는 독립 이미지 문서로 읽히므로 루트에 표준 네임스페이스를 선언해야 합니다.

<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 64 64">
  <path d="M32 4 58 56H6Z" fill="#D8A84B"/>
</svg>

xmlns="http://www.w3.org/2000/svg" 값은 정확히 한 번 허용됩니다. 일반적인 http: 외부 참조가 허용된다는 뜻은 아닙니다.

거부되는 SVG 기능

스크립트, 이벤트 속성, 외부 URL, 데이터 URL, image 삽입, 애니메이션과 원격 글꼴은 허용하지 않습니다. 정적 도형과 로컬 색상만 사용하세요.

마커 배치 값

필드형식설명
path상대 경로팩 내부 이미지 파일
displayWidth숫자기본 표시 너비
displayHeight숫자기본 표시 높이
anchorX0~1이미지 안의 좌우 기준점
anchorY0~1이미지 안의 상하 기준점
rotateWithHeading불리언선수각과 함께 회전할지 여부

앱 아이콘 PNG

appIcon.window는 PNG만 지원합니다. 파일은 512KB 이하, 16~512px 정사각형이어야 하며 투명 배경을 권장합니다. 이 자산은 네비게이터 창 아이콘에만 적용되고 공용 트레이 아이콘에는 적용되지 않습니다.
